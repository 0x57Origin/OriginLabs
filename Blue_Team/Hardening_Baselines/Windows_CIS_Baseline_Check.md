# Windows CIS Baseline Check - Center For Internet Security

---

We will scan a Windows 11 machine using CIS-CAT Lite, then record the baseline score & pull the failed controls worth fixing.

---

I am going to do this on my windows 11 but if you are doing it I suggest doing it on a Windows 11 VM and make sure to take a VM snapshot, name it something like pre-CIS-baseline. We will also find the exact Windows 11 build we have, so the scores can be tied to the specific build. We will also Download CIS-CAT Lite from the CIS website.
